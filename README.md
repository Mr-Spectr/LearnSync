
#                                                                                            Welcome to LearnSync

![LearnSync Banner](https://img.shields.io/badge/-LearnSync-blue?style=for-the-badge&logo=python)

🎓 **LearnSync** is an interactive desktop-based career path advisory platform built using Python's Tkinter GUI toolkit. It empowers learners by guiding them through personalized career pathways with skill sets, resources, and chatbot assistance. Whether you're a budding software engineer or a blockchain enthusiast — LearnSync has got you covered!

---

## 🚀 Features

✅ **Setup & Login Interface**  
Secure and easy account setup & login system using locally stored credentials.

✅ **Interactive GUI**  
User-friendly interface with modern styling and responsive buttons.

✅ **Career Advisor Engine**  
Get detailed information about career paths including:
- Required Skills
- Recommended Resources

✅ **Integrated Chatbot**  
Your AI buddy to resolve queries and provide suggestions.

✅ **Account Management**  
Logout or delete your account with a single click.

---

## 🛠️ Getting Started

### 🔧 Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Mr-Spectr/LearnSync.git
   cd LearnSync
   ```
2. Make sure Python 3 is installed.
3. Run the app:
   ```bash
   python learnsync.py
   ```

> 💡 **Note:** Add your `hello.ico` icon file to the correct path in the code or update the path.
